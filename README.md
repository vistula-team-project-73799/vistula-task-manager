# Vistula Task Manager

Simple Task Manager made for the Team Project – IT course (Practical Assignment 1).

**Student ID:** 73799

## Links

- Live app: https://vistula-team-project-73799.github.io/vistula-task-manager/
- Repository: https://github.com/vistula-team-project-73799/vistula-task-manager

## Technologies

- HTML, CSS, JavaScript (no framework)
- Supabase (PostgreSQL + auto-generated REST API)
- GitHub Pages

## Features

- Show all tasks from the database
- Add, edit and delete tasks
- Mark tasks as completed / not completed
- Error message if something goes wrong
